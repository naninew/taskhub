# Nơi lưu output test thật của ngày này

Quy tắc đặt tên file: `YYYYMMDD-<mo-ta-ngan>.<ext>` (ví dụ: `20260731-pytest.log`, `20260731-workspace-rbac.json`).

Không xoá file cũ của các lần chạy trước trong folder này — nếu chạy lại nhiều lần trong cùng ngày, thêm hậu tố `-v2`, `-v3`... để giữ lịch sử.

File trong folder này là BẰNG CHỨNG THẬT (log terminal, response JSON, output lint/test...) — không phải nội dung do viết tay/giả lập.
